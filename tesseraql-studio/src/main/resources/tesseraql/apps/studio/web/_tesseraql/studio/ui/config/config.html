Configuration

The app's effective configuration — application.yml, tesseraql.yml and overlay.yml merged, flattened to dotted keys. Values are shown unresolved, so an ${ENV} reference stays visible rather than its value; a secret's literal value is redacted. Read-only.

Editable settings

A curated set of safe settings. A change is written to config/overlay.yml (the base config is left intact) and applied on the next restart; clearing a value removes the override. Engine-critical settings (datasources, security, Camel) are not editable here.
