Bearer token

A token carries the subject, roles and permissions this session already holds — nothing more. It is for callers that have an account but cannot carry a cookie: CI, scripts, and the assistants that run on your own machine.

This application does not issue tokens.

Set tesseraql.security.token.enabled to true in the application configuration. It only works where TesseraQL holds the signing key — an application verifying RS256 against a publicKey or jwksUri has no private key to sign with, and refuses to start with TQL-SEC-4146 rather than answering 500 per request.

Tokens from this application last 15m. They cannot be revoked before they expire — a password change ends every session and does not reach a token already minted from one.

Copy it now. It is a credential that carries none of the session cookie's protections and outlives it, and this page cannot show it again.

tesseraql token --url https://this-host --login you
